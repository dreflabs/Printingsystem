# 14-USER-STORIES

Direktori ini berisi dokumentasi *User Stories* (cerita pengguna) dan *Acceptance Criteria* (kriteria penerimaan) untuk fitur-fitur pada aplikasi Print Pilot. 

Dokumentasi ini bertujuan untuk menjabarkan kebutuhan fitur dari sudut pandang pengguna yang akan menggunakan aplikasi ini (misalnya Admin, Kasir, Operator Cetak, dll).

## Format User Story
Format penulisan umum yang bisa digunakan:
> **Sebagai** [Role/Peran], **saya ingin** [Tujuan/Kebutuhan], **sehingga** [Alasan/Manfaat].
