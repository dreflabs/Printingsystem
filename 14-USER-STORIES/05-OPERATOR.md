# User Story: Operator Mesin Cetak

Operator mesin bertanggung jawab untuk menerima file final dari desainer, mengatur antrean mesin, dan memastikan hasil cetak keluar dengan kualitas yang baik.

## 1. Manajemen Antrean Mesin
- **Sebagai** Operator, **saya ingin** melihat daftar pekerjaan (Job Ticket) yang dialokasikan untuk mesin saya, **sehingga** saya bisa memprioritaskan pekerjaan berdasarkan urgensi atau jenis bahan.
- **Sebagai** Operator, **saya ingin** mengunduh file *ready-to-print* dengan satu klik, **sehingga** saya tidak perlu mencari-cari file desain di folder komputer secara manual.
- **Sebagai** Operator, **saya ingin** mengubah status pekerjaan menjadi "Sedang Dicetak", **sehingga** kasir dan pelanggan tahu bahwa pesanan mereka sedang dalam proses produksi.

## 2. Pelaporan Kerusakan / Masalah
- **Sebagai** Operator, **saya ingin** bisa melaporkan (flag) masalah pada pesanan jika file desain ternyata korup atau ukuran tidak sesuai, **sehingga** pesanan otomatis kembali ke antrean revisi desainer.
- **Sebagai** Operator, **saya ingin** mencatat jika ada hasil cetakan yang gagal (waste/buangan) beserta jumlahnya, **sehingga** owner memiliki data untuk evaluasi kualitas bahan atau performa mesin.

## 3. Penyelesaian & Handover
- **Sebagai** Operator, **saya ingin** mengubah status pesanan menjadi "Selesai Cetak", **sehingga** pekerjaan otomatis diteruskan ke tim Finishing jika diperlukan (misal untuk potong, laminasi, jilid).
- **Sebagai** Operator, **saya ingin** mencetak label produksi yang ditempel di hasil cetakan, **sehingga** tim finishing tahu instruksi selanjutnya tanpa harus bertanya kepada saya.
