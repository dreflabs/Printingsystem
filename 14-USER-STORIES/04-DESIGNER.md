# User Story: Designer

Designer bertugas menyiapkan file siap cetak dari pelanggan atau membuat desain dari nol sesuai instruksi pada pesanan.

## 1. Antrean Desain
- **Sebagai** Designer, **saya ingin** melihat daftar pesanan yang masuk dan berstatus "Menunggu Desain", **sehingga** saya tahu pekerjaan apa yang harus saya selesaikan.
- **Sebagai** Designer, **saya ingin** bisa mengambil ("claim") sebuah pesanan dari antrean, **sehingga** desainer lain tahu bahwa pesanan tersebut sudah saya tangani dan tidak terjadi pengerjaan ganda.
- **Sebagai** Designer, **saya ingin** melihat catatan dan file lampiran dari kasir atau pelanggan, **sehingga** saya memiliki konteks dan materi yang cukup untuk mulai mendesain.

## 2. Proses Pra-Cetak
- **Sebagai** Designer, **saya ingin** mengunggah file yang sudah final (ready-to-print) ke dalam pesanan, **sehingga** operator mesin bisa langsung mengunduh dan mencetaknya.
- **Sebagai** Designer, **saya ingin** memberikan catatan teknis ke operator (misal: "print di mesin A, profil warna CMYK standar"), **sehingga** hasil cetakan sesuai dengan ekspektasi warna desain.
- **Sebagai** Designer, **saya ingin** mengubah status pesanan dari "Sedang Didesain" menjadi "Menunggu Cetak", **sehingga** pekerjaan otomatis berpindah ke antrean dashboard Operator.

## 3. Revisi
- **Sebagai** Designer, **saya ingin** menerima notifikasi jika pesanan dikembalikan oleh operator karena file resolusinya pecah atau salah ukuran, **sehingga** saya bisa segera memperbaikinya tanpa mengganggu flow operator lebih lama.
